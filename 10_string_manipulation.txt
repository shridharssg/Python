✅ TOPIC 9: STRING MANIPULATION (PYTHON) WITH OUTPUTS
============================================================


============================================================
✅ BASIC OPERATIONS
============================================================

------------------------------------------------------------
🔹 ✅ Concatenation
------------------------------------------------------------
	first = "Hello"
	second = "World"

	result = first + " " + second
	print(result)

Output:
	Hello World

------------------------------------------------------------
🔹 ✅ Repetition
------------------------------------------------------------
	print("Hi " * 3)

Output:
	Hi Hi Hi 

------------------------------------------------------------
🔹 ✅ Access Characters
------------------------------------------------------------
	text = "Python"

	print(text[0])
	print(text[-1])

Output:
	P
	n

============================================================
✅ STRING METHODS
============================================================

------------------------------------------------------------
🔹 ✅ lower()
------------------------------------------------------------
	text = "HELLO"
	print(text.lower())

Output:
	hello

------------------------------------------------------------
🔹 ✅ upper()
------------------------------------------------------------
	text = "hello"
	print(text.upper())

Output:
	HELLO

------------------------------------------------------------
🔹 ✅ strip()
------------------------------------------------------------
	text = "  hello  "
	print(text.strip())

Output:
	hello

------------------------------------------------------------
🔹 ✅ replace()
------------------------------------------------------------
	text = "Hello World"
	print(text.replace("World", "AI"))

Output:
	Hello AI

------------------------------------------------------------
🔹 ✅ split()
------------------------------------------------------------
	text = "Python AWS GenAI"
	print(text.split())

Output:
	['Python', 'AWS', 'GenAI']

------------------------------------------------------------
🔹 ✅ join()
------------------------------------------------------------
	words = ["Python", "AWS", "GenAI"]
	print(" ".join(words))

Output:
	Python AWS GenAI

------------------------------------------------------------
🔹 ✅ find()
------------------------------------------------------------
	text = "Hello World"
	print(text.find("World"))

Output:
	6

------------------------------------------------------------
🔹 ✅ startswith() / endswith()
------------------------------------------------------------
	text = "Python"

	print(text.startswith("Py"))
	print(text.endswith("on"))

Output:
	True
	True

============================================================
✅ IMPORTANT OPERATIONS
============================================================

------------------------------------------------------------
🔹 ✅ Check substring
------------------------------------------------------------
	text = "Python GenAI"

	print("GenAI" in text)

Output:
	True

------------------------------------------------------------
🔹 ✅ Length
------------------------------------------------------------
	print(len("Python"))

Output:
	6

============================================================
✅ STRING FORMATTING (VERY IMPORTANT)
============================================================

------------------------------------------------------------
🔹 ✅ f-string
------------------------------------------------------------
	name = "Shridhar"
	exp = 9

	print(f"{name} has {exp} years experience")

Output:
	Shridhar has 9 years experience
