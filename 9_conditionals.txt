
============================================================
✅ TOPIC 8: CONDITIONAL STATEMENTS (IF, ELSE, ELIF)
============================================================

============================================================
✅ TYPES OF CONDITIONAL STATEMENTS
============================================================

	✔ if
	✔ if-else
	✔ if-elif-else

============================================================
✅ 1. IF STATEMENT
============================================================

------------------------------------------------------------
🔹 ✅ Syntax
------------------------------------------------------------

	if condition:
	    # code

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	age = 20

	if age >= 18:
	    print("Adult")

Output:
	Adult

============================================================
✅ 2. IF - ELSE STATEMENT
============================================================

------------------------------------------------------------
🔹 ✅ Syntax
------------------------------------------------------------

	if condition:
	    # code
	else:
	    # code

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	age = 16

	if age >= 18:
	    print("Adult")
	else:
	    print("Minor")

Output:
	Minor

============================================================
✅ 3. IF - ELIF - ELSE
============================================================

------------------------------------------------------------
🔹 ✅ Syntax
------------------------------------------------------------

	if condition:
	    # code
	elif condition:
	    # code
	else:
	    # code

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	marks = 75

	if marks >= 90:
	    print("Grade A")
	elif marks >= 70:
	    print("Grade B")
	else:
	    print("Grade C")

Output:
	Grade B

============================================================
✅ 4. MULTIPLE CONDITIONS
============================================================

------------------------------------------------------------
🔹 ✅ AND Operator
------------------------------------------------------------

	age = 25
	has_id = True

	if age >= 18 and has_id:
	    print("Allowed")

Output:
	Allowed

------------------------------------------------------------
🔹 ✅ OR Operator
------------------------------------------------------------

	is_admin = False
	is_manager = True

	if is_admin or is_manager:
	    print("Access granted")

Output:
	Access granted

------------------------------------------------------------
🔹 ✅ NOT Operator
------------------------------------------------------------

	is_logged_in = False

	if not is_logged_in:
	    print("Please login")

Output:
	Please login
	




============================================================
✅ 5. NESTED IF
============================================================

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	age = 25
	salary = 50000

	if age > 18:
	    if salary > 40000:
	        print("Eligible")

Output:
	Eligible

============================================================
✅ 6. SHORT HAND (ONE LINE IF)
============================================================

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	age = 20

	print("Adult") if age >= 18 else print("Minor")

Output:
	Adult

============================================================

------------------------------------------------------------
🔹 Checking Skills
------------------------------------------------------------

	skills = ["Python", "ML"]

	if "Python" in skills:
	    print("Python found")

Output:
	Python found

============================================================

❌ COMMON MISTAKES
============================================================

	if age > 18   ❌

✅ Correct:
	if age > 18:

	if age > 18:
	print("Adult") ❌

✅ Correct:
	if age > 18:
	    print("Adult")
