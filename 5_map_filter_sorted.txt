
============================================================
✅ TOPIC 6: MAP, FILTER, SORTED (PYTHON)
============================================================

------------------------------------------------------------
✅ 1. MAP() (TRANSFORMATION)
------------------------------------------------------------

🔹 ✅ Definition
map() is used to apply a function to every element in a list.

👉 map = “convert each item”

------------------------------------------------------------
🔹 ✅ Why Used
------------------------------------------------------------
	✔ Transform data
	✔ Modify list values
	✔ Common in data pipelines (GenAI)

------------------------------------------------------------
🔹 ✅ Syntax
------------------------------------------------------------

	map(function, iterable)

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	nums = [1, 2, 3]

	result = list(map(lambda x: x * 2, nums))

	print(result)

Output:
	[2, 4, 6]

------------------------------------------------------------
🔹 ✅ Without map
------------------------------------------------------------

	result = []

	for x in nums:
	    result.append(x * 2)


------------------------------------------------------------
🔹 ✅ When to Use ✅
------------------------------------------------------------

	✔ Same logic on all items
	✔ Data transformation



============================================================
✅ 2. FILTER() (SELECTION)
============================================================

------------------------------------------------------------
🔹 ✅ Definition
------------------------------------------------------------

filter() keeps elements that satisfy a condition.

👉 filter = “keep matching items”

------------------------------------------------------------
🔹 ✅ Why Used
------------------------------------------------------------

	✔ Remove unwanted data
	✔ Select specific values

------------------------------------------------------------
🔹 ✅ Syntax
------------------------------------------------------------

	filter(function, iterable)

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	nums = [1, 2, 3, 4]

	result = list(filter(lambda x: x % 2 == 0, nums))

	print(result)

Output:
	[2, 4]

------------------------------------------------------------
🔹 ✅ Without filter
------------------------------------------------------------

	result = []

	for x in nums:
	    if x % 2 == 0:
	        result.append(x)

------------------------------------------------------------



============================================================
✅ 3. SORTED() (SORTING)
============================================================

------------------------------------------------------------
🔹 ✅ Definition
------------------------------------------------------------

sorted() is used to sort elements in a list.

------------------------------------------------------------
🔹 ✅ Syntax
------------------------------------------------------------

	sorted(iterable, key=function, reverse=False)

------------------------------------------------------------
🔹 ✅ Basic Example
------------------------------------------------------------

	nums = [3, 1, 2]

	result = sorted(nums)

	print(result)

Output:
	[1, 2, 3]

------------------------------------------------------------
🔹 ✅ Descending Order
------------------------------------------------------------

	result = sorted(nums, reverse=True)

	print(result)

------------------------------------------------------------
🔹 ✅ Sorting with Key
------------------------------------------------------------

	data = [(1, 3), (2, 1), (3, 2)]

	result = sorted(data, key=lambda x: x[1])

	print(result)

Output:
	[(2, 1), (3, 2), (1, 3)]

------------------------------------------------------------
🔹 ✅ Real GenAI Use Case
------------------------------------------------------------

	candidates = [
	    {"name": "A", "score": 8},
	    {"name": "B", "score": 9},
	]

	sorted_candidates = sorted(
	    candidates,
	    key=lambda x: x["score"],
	    reverse=True
	)

	print(sorted_candidates)

------------------------------------------------------------
🔹 ✅ When to Use ✅
------------------------------------------------------------

	✔ Sorting data
	✔ Ranking outputs

-----------------------------------------------------------

✅ KEY DIFFERENCE
============================================================

	map()    → transform data
	filter() → select data
	sorted() → order data


============================================================
✅ COMBINED EXAMPLE
============================================================

	nums = [1, 2, 3, 4, 5]

	result = sorted(
	    filter(lambda x: x % 2 == 0, nums)
	)

	print(result)

Output:
	[2, 4]
