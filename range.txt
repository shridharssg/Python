=========================================================
PYTHON range() COMPLETE INTERVIEW GUIDE
=========================================================

range() is one of the most used functions in Python.

Syntax:

range(start, stop, step)

---------------------------------------------------------
Parameter Meaning
---------------------------------------------------------

start
------
Where to begin

stop
-----
Where to stop (NOT INCLUDED)

step
-----
How much to move every time

=========================================================
1. range(stop)
=========================================================

Example:

for i in range(5):
    print(i)

Output:

0
1
2
3
4

Explanation:

Python starts from 0 by default.

range(5)

means

0 → 4

---------------------------------------------------------

Visual:

0 1 2 3 4

=========================================================
2. range(start, stop)
=========================================================

Example:

for i in range(2, 6):
    print(i)

Output:

2
3
4
5

Explanation:

Start = 2
Stop = 6 (excluded)

---------------------------------------------------------

Visual:

2 3 4 5

NOT:

6

=========================================================
3. range(start, stop, step)
=========================================================

Example:

for i in range(1, 10, 2):
    print(i)

Output:

1
3
5
7
9

Explanation:

Start = 1

Move by 2 each time

1 → 3 → 5 → 7 → 9

=========================================================
4. Print Even Numbers
=========================================================

Example:

for i in range(2, 11, 2):
    print(i)

Output:

2
4
6
8
10

Explanation:

Start = 2

Jump = 2

=========================================================
5. Print Odd Numbers
=========================================================

Example:

for i in range(1, 11, 2):
    print(i)

Output:

1
3
5
7
9

=========================================================
6. Reverse Loop
=========================================================

Example:

for i in range(5, 0, -1):
    print(i)

Output:

5
4
3
2
1

Explanation:

Start = 5

Move backward using -1

---------------------------------------------------------

Visual:

5
↓
4
↓
3
↓
2
↓
1

=========================================================
7. Reverse List Example
=========================================================

Input:

arr = [10,20,30,40,50]

Index:

0 1 2 3 4

Code:

for i in range(len(arr)-1, -1, -1):
    print(arr[i])

Output:

50
40
30
20
10

---------------------------------------------------------

Explanation:

len(arr)=5

Last Index=5 - 1=4

So:

range(4, -1, -1)

Means:

4
3
2
1
0

we want upto 0 index so 2nd parameter is -1

=========================================================
15. Nested Loop Pattern
=========================================================

for i in range(1, 4):

    for j in range(1, 4):

        print(j, end=" ")

    print()

Output:

1 2 3
1 2 3
1 2 3
