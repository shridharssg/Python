
============================================================
✅ TOPIC 2: LISTS, DICTIONARIES, TUPLES (PYTHON)
============================================================


	✔ Use LIST → multiple items
	✔ Use DICTIONARY → structured data
	✔ Use TUPLE → fixed data


------------------------------------------------------------
✅ 1. LIST
------------------------------------------------------------

	🔹 ✅ Definition
		A list is an ordered, changeable (mutable) collection of items.

		👉 List = “array in Node.js”

	------------------------------------------------------------
	🔹 ✅ Why Used
	------------------------------------------------------------
		✔ Store multiple values
		✔ Maintain order
		✔ Modify data easily

	------------------------------------------------------------
	🔹 ✅ How It Works
	------------------------------------------------------------

		skills = ["Python", "AWS", "Node.js"]

		✔ Ordered
		✔ Indexed (skills[0])
		✔ Changeable

	------------------------------------------------------------
	🔹 ✅ Example
	------------------------------------------------------------

		skills = ["Python", "AWS", "Node.js"]

		print(skills[0])

		skills.append("GenAI")

		print(skills)

	Output:
		['Python', 'AWS', 'Node.js', 'GenAI']

	------------------------------------------------------------
	🔹 ✅ Real GenAI Use Case
	------------------------------------------------------------

		skills = ["Python", "ML", "NLP"]
		prompt = f"Evaluate candidate with skills: {skills}"

	------------------------------------------------------------
	🔹 ✅ When to Use LIST ✅
	------------------------------------------------------------

		✔ Ordered data needed
		✔ Need to modify/add/remove items
		✔ No key-value structure required

	------------------------------------------------------------
	🔹 ❌ When NOT to Use LIST
	------------------------------------------------------------

		❌ When data has key-value structure → use dict
		❌ When data should NOT change → use tuple


============================================================
✅ 2. DICTIONARY
============================================================

	------------------------------------------------------------
	🔹 ✅ Definition
	------------------------------------------------------------

	A dictionary is a key-value pair collection.

	👉 Dictionary = JSON object (Node.js)

	------------------------------------------------------------
	🔹 ✅ Why Used
	------------------------------------------------------------

		✔ Store structured data
		✔ Fast lookup using key
		✔ Used in APIs & GenAI

	------------------------------------------------------------
	🔹 ✅ How It Works
	------------------------------------------------------------

		user = {
			"name": "Shridhar",
			"experience": 9,
			"skills": ["Python", "AWS"]
		}

	------------------------------------------------------------
	🔹 ✅ Example
	------------------------------------------------------------

		user = {
			"name": "Shridhar",
			"experience": 9
		}

		print(user["name"])

		user["city"] = "Pune"

		print(user)

	------------------------------------------------------------
	🔹 ✅ Real GenAI Use Case
	------------------------------------------------------------

		response = {
			"summary": "Good candidate",
			"score": 8.5,
			"skills": ["Python", "AI"]
		}

	------------------------------------------------------------
	🔹 ✅ When to Use DICTIONARY ✅
	------------------------------------------------------------

		✔ Structured key-value data
		✔ APIs / JSON handling
		✔ Fast lookup required

	------------------------------------------------------------
	🔹 ❌ When NOT to Use DICTIONARY
	------------------------------------------------------------

		❌ Simple list of values → use list
		❌ Order-only requirement → use list/tuple


============================================================
✅ 3. TUPLE
============================================================

	------------------------------------------------------------
	🔹 ✅ Definition
	------------------------------------------------------------

	A tuple is an ordered, unchangeable (immutable) collection.

	👉 Tuple = “fixed list”

	------------------------------------------------------------
	🔹 ✅ Why Used
	------------------------------------------------------------

		✔ Store constant data
		✔ Faster than list
		✔ Prevent accidental changes

	------------------------------------------------------------
	🔹 ✅ How It Works
	------------------------------------------------------------

		coordinates = (10, 20)

	------------------------------------------------------------
	🔹 ✅ Example
	------------------------------------------------------------

		point = (10, 20)

		print(point[0])

		# point[0] = 50  ❌ ERROR

	------------------------------------------------------------
	🔹 ✅ Real GenAI Use Case
	------------------------------------------------------------

		model_config = ("gpt-4o-mini", 0.7, 200)

	------------------------------------------------------------
	🔹 ✅ When to Use TUPLE ✅
	------------------------------------------------------------

		✔ Data should be unchangeable
		✔ Constants
		✔ Performance optimization

	------------------------------------------------------------
	🔹 ❌ When NOT to Use TUPLE
	------------------------------------------------------------

		❌ Need to modify data → use list
		❌ Structured data → use dict


============================================================
✅ FINAL COMPARISON
============================================================

	List        → Changeable, ordered collection
	Dictionary  → Key-value structured data
	Tuple       → Fixed, unchangeable data


============================================================
✅ REAL SCENARIO (INTERVIEW LEVEL 🔥)
============================================================

❌ Wrong (List):
	data = ["Shridhar", 9, "Python"]

✅ Correct (Dictionary):
	data = {
	    "name": "Shridhar",
	    "experience": 9,
	    "skill": "Python"
	}

✅ List inside Dictionary:
	data = {
	    "name": "Shridhar",
	    "skills": ["Python", "AWS", "GenAI"]
	}
