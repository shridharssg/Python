
============================================================
✅ TOPIC 7: LOOPS IN PYTHON 
============================================================

	for loop   → fixed iterations ✅
	while loop → condition-based ✅


------------------------------------------------------------

============================================================
✅ 1. FOR LOOP
============================================================

------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	nums = [1, 2, 3]

	for num in nums:
	    print(num)

Output:
	1
	2
	3

------------------------------------------------------------
🔹 ✅ Loop with String
------------------------------------------------------------

	for ch in "AI":
	    print(ch)

Output:
	A
	I

------------------------------------------------------------
🔹 ✅ Loop with range()
------------------------------------------------------------

	for i in range(5):
	    print(i)

Output:
	0
	1
	2
	3
	4

------------------------------------------------------------
🔹 ✅ Loop with index
------------------------------------------------------------

	skills = ["Python", "AWS"]

	for i in range(len(skills)):
	    print(i, skills[i])

Output:
	0 Python
	1 AWS

------------------------------------------------------------

	skills = ["Python", "ML", "NLP"]

	for skill in skills:
	    print(f"Checking skill: {skill}")

Output:
	Checking skill: Python
	Checking skill: ML
	Checking skill: NLP

============================================================


✅ 2. WHILE LOOP
============================================================

------------------------------------------------------------
🔹 ✅ Definition
------------------------------------------------------------
Used to run code while condition is true

------------------------------------------------------------
🔹 ✅ Syntax
------------------------------------------------------------

	while condition:
	    # code
		
------------------------------------------------------------
🔹 ✅ Example
------------------------------------------------------------

	i = 0

	while i < 5:
	    print(i)
	    i += 1

Output:
	0
	1
	2
	3
	4

------------------------------------------------------------
🔹 ✅ Infinite Loop (Caution)
------------------------------------------------------------

	while True:
	    print("Hello")

Output:
	Runs forever (infinite loop)

------------------------------------------------------------
🔹 ✅ Real GenAI Use Case
------------------------------------------------------------

	retry = 0

	while retry < 3:
	    print("Calling API...")
	    retry += 1

Output:
	Calling API...
	Calling API...
	Calling API...

============================================================
✅ LOOP CONTROL STATEMENTS
============================================================

------------------------------------------------------------
🔹 ✅ break
------------------------------------------------------------

	for i in range(5):
	    if i == 3:
	        break
	    print(i)

Output:
	0
	1
	2

------------------------------------------------------------
🔹 ✅ continue
------------------------------------------------------------

	for i in range(5):
	    if i == 2:
	        continue
	    print(i)

Output:
	0
	1
	3
	4

------------------------------------------------------------
🔹 ✅ pass
------------------------------------------------------------

	for i in range(3):
	    pass

Output:
	(No output)

============================================================
✅ SUMMARY
============================================================

	✔ for → data iteration
	✔ while → condition logic
	✔ break → stop loop
	✔ continue → skip iteration

============================================================
