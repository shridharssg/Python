=========================================================
PYTHON LIST METHODS
=========================================================

---------------------------------------------------------
✅ 1. append()
---------------------------------------------------------

Description:

Adds a single element at the end of the list.

Input:

numbers = [1, 2, 3]

Solution:

numbers.append(4)

print(numbers)

Output:

[1, 2, 3, 4]

---------------------------------------------------------
✅ 2. extend()
---------------------------------------------------------

Description:

Adds multiple elements from another iterable.

Input:

a = [1, 2]
b = [3, 4]

Solution:

a.extend(b)

print(a)

Output:

[1, 2, 3, 4]

---------------------------------------------------------
✅ 3. insert()
---------------------------------------------------------

Description:

Inserts element at a specific position.

Input:

numbers = [1, 2, 4]

Solution:

numbers.insert(2, 3)

print(numbers)

Output:

[1, 2, 3, 4]

---------------------------------------------------------
✅ 4. remove()
---------------------------------------------------------

Description:

Removes first occurrence of given value.

numbers = [1, 2, 3, 2]

print(numbers)

Output:

[1, 3, 2]

---------------------------------------------------------
✅ 5. pop()
---------------------------------------------------------

Description:

Removes and returns element by index.
Default is last element.

Input:

numbers = [1, 2, 3]

Solution:

value = numbers.pop()

print(value)
print(numbers)

Output:

3
[1, 2]
