------------------------------------------------------------
🔹 1. ✅ append()
------------------------------------------------------------
Adds element at the end (like push)

	nums = [1, 2, 3]
	nums.append(4)

	print(nums)  # [1, 2, 3, 4]

👉 Node.js: push()

------------------------------------------------------------
🔹 2. ✅ extend()
------------------------------------------------------------
Adds multiple elements

	nums = [1, 2]
	nums.extend([3, 4])

	print(nums)  # [1, 2, 3, 4]

👉 Node.js: push(...arr)

------------------------------------------------------------
🔹 3. ✅ insert(index, value)
------------------------------------------------------------
Add element at specific position

	nums = [1, 2, 3]
	nums.insert(1, 10)

	print(nums)  # [1, 10, 2, 3]

------------------------------------------------------------
🔹 4. ✅ remove(value)
------------------------------------------------------------
Remove specific value (first occurrence)

	nums = [1, 2, 3]
	nums.remove(2)

	print(nums)  # [1, 3]

------------------------------------------------------------
🔹 5. ✅ pop()
------------------------------------------------------------
Remove element by index (default last)

	nums = [1, 2, 3]
	nums.pop()

	print(nums)  # [1, 2]

👉 Node.js: pop()

------------------------------------------------------------
🔹 6. ✅ clear()
------------------------------------------------------------
Remove all elements

	nums = [1, 2, 3]
	nums.clear()

	print(nums)  # []

------------------------------------------------------------
🔹 7. ✅ index(value)
------------------------------------------------------------
Find index of element

	nums = [10, 20, 30]
	print(nums.index(20))  # 1

👉 Node.js: indexOf()

------------------------------------------------------------
🔹 8. ✅ count(value)
------------------------------------------------------------
Count occurrences

	nums = [1, 2, 2, 3]
	print(nums.count(2))  # 2

------------------------------------------------------------
🔹 9. ✅ sort()
------------------------------------------------------------
Sort list

	nums = [3, 1, 2]
	nums.sort()

	print(nums)  # [1, 2, 3]

------------------------------------------------------------
🔹 10. ✅ reverse()
------------------------------------------------------------
Reverse list

	nums = [1, 2, 3]
	nums.reverse()

	print(nums)  # [3, 2, 1]

------------------------------------------------------------
🔹 11. ✅ copy()
------------------------------------------------------------
Copy list

	nums = [1, 2, 3]
	new_nums = nums.copy()

------------------------------------------------------------
🔹 12. ✅ len() (Function)
------------------------------------------------------------
Get length

	nums = [1, 2, 3]
	print(len(nums))  # 3

👉 Node.js: array.length

------------------------------------------------------------
✅ COMMON OPERATIONS (VERY IMPORTANT)
------------------------------------------------------------

🔹 ✅ Check element exists (like includes())

	nums = [1, 2, 3]
	print(2 in nums)  # True

👉 Node.js: includes()

------------------------------------------------------------
🔹 ✅ Loop through list
------------------------------------------------------------

	for num in nums:
	    print(num)

------------------------------------------------------------
🔹 ✅ Access element
------------------------------------------------------------

	nums = [10, 20, 30]

	print(nums[0])   # 10
	print(nums[-1])  # 30 (last element)
