============================================================
            PYTHON LISTS vs JAVASCRIPT ARRAYS
============================================================

WHAT IS A LIST?
------------------------------------------------------------

A List is a collection of multiple values.

Python:

    nums = [10, 20, 30]

JavaScript:

    const nums = [10, 20, 30];

Features:

    ✔ Ordered
    ✔ Mutable (Can Modify)
    ✔ Allows Duplicates


============================================================
CREATE LIST / ARRAY
============================================================

Python:

    fruits = ["Apple", "Mango", "Banana"]

JavaScript:

    const fruits = ["Apple", "Mango", "Banana"];


============================================================
ACCESS ELEMENTS
============================================================

First Element

Python:

    nums[0]

JavaScript:

    nums[0]

------------------------------------------------------------

Last Element

Python:

    nums[-1]

JavaScript:

    nums[nums.length - 1]


============================================================
ADD ELEMENTS
============================================================

Add One Element

Python:

    nums.append(40)

JavaScript:

    nums.push(40)

------------------------------------------------------------

Add Multiple Elements

Python:

    nums.extend([50, 60])

JavaScript:

    nums.push(...[50, 60])

------------------------------------------------------------

Insert At Specific Position

Python:

    nums.insert(1, 15)

JavaScript:

    nums.splice(1, 0, 15)


============================================================
REMOVE ELEMENTS
============================================================

Remove By Value

Python:

    nums.remove(20)

JavaScript:

    let index = nums.indexOf(20);

    nums.splice(index, 1);

------------------------------------------------------------

Remove Last Element

Python:

    nums.pop()

JavaScript:

    nums.pop()

------------------------------------------------------------

Remove By Index

Python:

    nums.pop(1)

JavaScript:

    nums.splice(1, 1)

------------------------------------------------------------

Remove Everything

Python:

    nums.clear()

JavaScript:

    nums.length = 0


============================================================
SEARCH OPERATIONS
============================================================

Check Element Exists

Python:

    20 in nums

JavaScript:

    nums.includes(20)

------------------------------------------------------------

Find Index

Python:

    nums.index(20)

JavaScript:

    nums.indexOf(20)

------------------------------------------------------------

Count Occurrences

Python:

    nums.count(20)

JavaScript:

    nums.filter(x => x === 20).length


============================================================
SORTING
============================================================

Ascending Sort

Python:

    nums.sort()

JavaScript:

    nums.sort((a, b) => a - b)

------------------------------------------------------------

Reverse

Python:

    nums.reverse()

JavaScript:

    nums.reverse()


============================================================
COPY LIST / ARRAY
============================================================

Python:

    new_nums = nums.copy()

JavaScript:

    const newNums = [...nums]


============================================================
LENGTH
============================================================

Python:

    len(nums)

JavaScript:

    nums.length


============================================================
LOOPING
============================================================

Python:

    for num in nums:

        print(num)

JavaScript:

    for(const num of nums){

        console.log(num);

    }


============================================================
MOST COMMON INTERVIEW PROGRAMS
============================================================

1. Find Largest Number

Python:

    nums = [10, 5, 30, 20]

    print(max(nums))

Output:

    30

JavaScript:

    console.log(Math.max(...nums))


------------------------------------------------------------

2. Find Smallest Number

Python:

    print(min(nums))

JavaScript:

    console.log(Math.min(...nums))


------------------------------------------------------------

3. Find Sum Of Elements

Python:

    print(sum(nums))

JavaScript:

    console.log(
        nums.reduce((a,b) => a+b, 0)
    )


------------------------------------------------------------

4. Check Element Exists

Python:

    if 30 in nums:

        print("Found")

JavaScript:

    if(nums.includes(30)){

        console.log("Found");

    }


------------------------------------------------------------

5. Remove Duplicates

Python:

    nums = list(set(nums))

JavaScript:

    nums = [...new Set(nums)]
