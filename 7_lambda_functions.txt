
============================================================
✅ TOPIC 5 (EXTENDED): LAMBDA FUNCTIONS (PYTHON)
============================================================

------------------------------------------------------------
🔹 ✅ 1. Definition
------------------------------------------------------------

A lambda function is a small anonymous (no name) function written in one line.

👉 Lambda = “shortcut function”

------------------------------------------------------------
🔹 ✅ 2. Why Used
------------------------------------------------------------

	✔ Write short, quick logic
	✔ Avoid defining full function
	✔ Used in data processing (lists, sorting)
	✔ Used in GenAI pipelines for transformations

------------------------------------------------------------
🔹 ✅ 3. Syntax
------------------------------------------------------------

	lambda arguments: expression

------------------------------------------------------------
🔹 ✅ 4. Basic Example
------------------------------------------------------------

✅ Normal function:
	def add(a, b):
	    return a + b

✅ Lambda version:
	add = lambda a, b: a + b

	print(add(2, 3))  # 5

------------------------------------------------------------
🔹 ✅ 5. Simple Example
------------------------------------------------------------

	square = lambda x: x * x

	print(square(4))  # 16
	
	

------------------------------------------------------------
🔹 ✅ 6. With List (VERY IMPORTANT 🔥)
------------------------------------------------------------

✅ Using map()
	 nums = [1, 2, 3]

	 result = list(map(lambda x: x * 2, nums))

	 print(result)  # [2, 4, 6]

------------------------------------------------------------
✅ Using filter()

	 nums = [1, 2, 3, 4]

	 result = list(filter(lambda x: x % 2 == 0, nums))

	 print(result)  # [2, 4]

------------------------------------------------------------
✅ Using sorted()

	 data = [(1, 3), (2, 1), (3, 2)]

	 sorted_data = sorted(data, key=lambda x: x[1])

	 print(sorted_data)

Output:
	[(2, 1), (3, 2), (1, 3)]

------------------------------------------------------------
🔹 ✅ 7. Real GenAI Use Case 🔥
------------------------------------------------------------

✅ Processing LLM scores

	 scores = [8.5, 7.0, 9.2]

	 high_scores = list(filter(lambda x: x > 8, scores))

	 print(high_scores)

------------------------------------------------------------
✅ Formatting response

	 names = ["shridhar", "amit"]

	 formatted = list(map(lambda x: x.upper(), names))

	 print(formatted)

------------------------------------------------------------
🔹 ✅ 8. When to Use LAMBDA ✅
------------------------------------------------------------

	✔ Small one-line logic
	✔ Inside map(), filter(), sorted()
	✔ Quick transformations

------------------------------------------------------------
🔹 ❌ When NOT to Use LAMBDA
------------------------------------------------------------

	❌ Complex logic
	❌ Multiple statements
	❌ Hard-to-read code

👉 Instead use normal function

------------------------------------------------------------
🔹 ✅ 9. Lambda vs Normal Function
------------------------------------------------------------

	Lambda Function:
		✔ No name
		✔ One line
		✔ Used for small tasks

	Normal Function:
		✔ Has name
		✔ Multiple lines
		✔ Used for complex logic
