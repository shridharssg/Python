
============================================================
✅ TOPIC: CLEAN REQUIREMENTS.TXT (AVOID UNWANTED PACKAGES)
============================================================

------------------------------------------------------------
🔹 ✅ 1. Problem with pip freeze ❌
------------------------------------------------------------

Running:
	pip freeze > requirements.txt

👉 Includes ALL installed packages:
	✔ Your packages ✅
	❌ Unwanted dependencies (auto-installed)

Example:
	fastapi==0.x
	starlette==0.x   ❌ unwanted
	pydantic==2.x    ❌ unwanted

👉 File becomes messy ❌

------------------------------------------------------------
🔹 ✅ 2. Goal
------------------------------------------------------------

👉 Keep only top-level dependencies (like Node.js package.json)

Example:
	fastapi
	requests

------------------------------------------------------------
🔹 ✅ 3. Solutions (BEST METHODS)
------------------------------------------------------------

✅ OPTION 1: Manual Method (Recommended 👍)

	1. Install package:
		pip install fastapi

	2. Add manually in requirements.txt:
		fastapi

👉 Clean and controlled ✅

------------------------------------------------------------
✅ OPTION 2: Use pip freeze carefully
------------------------------------------------------------

	pip freeze

👉 Copy only required packages manually

👉 Avoid using > blindly ❌

------------------------------------------------------------
✅ OPTION 3: Use pipreqs (BEST 🔥)
------------------------------------------------------------

👉 Generates clean requirements based on code

Install:
	pip install pipreqs

Run:
	pipreqs .

Output:
	fastapi==0.x
	requests==2.x

👉 Only used packages ✅
👉 No extra dependencies ✅

------------------------------------------------------------
✅ OPTION 4: pip-tools (Advanced)
------------------------------------------------------------

Install:
	pip install pip-tools

Use:
	pip-compile

👉 Creates:
	requirements.in  (clean list ✅)
	requirements.txt (full dependencies ✅)

------------------------------------------------------------
🔹 ✅ 4. Node.js Comparison (IMPORTANT 🔥)
------------------------------------------------------------

✅ Node.js:
	npm install express

	👉 Updates package.json automatically ✅
	👉 Only main dependency shown ✅

✅ Python:
	pip install fastapi

	👉 Does NOT update requirements.txt ❌
	👉 Must manage manually ✅

------------------------------------------------------------
🔹 ✅ 5. Best Practice for YOU 🚀
------------------------------------------------------------

👉 Use this flow:

	pip install fastapi requests
	pipreqs .

👉 OR manually maintain:
	fastapi
	requests

------------------------------------------------------------
✅ SUMMARY
------------------------------------------------------------

	✔ pip freeze → includes everything ❌
	✔ Manual → clean ✅
	✔ pipreqs → best ✅
	✔ pip-tools → advanced ✅

------------------------------------------------------------
🎯 ONE LINE (IMPORTANT)
------------------------------------------------------------

	👉 Avoid pip freeze blindly — use pipreqs or manual method
