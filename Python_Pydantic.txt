1. WHAT IS THE PROBLEM?
------------------------------------------------------------

Suppose we receive data from an API.

    user = {

        "name": "John",

        "age": "25"
    }

Question:

    Is age integer?

Answer:

    No

It is String.

Problem:

    External systems often send
    incorrect data types.

We need validation.


============================================================
2. TYPE HINT PROBLEM
============================================================

Example:

    def create_user(age: int):

        print(age)

Call:

    create_user("25")

Still works.

Why?

    Type Hints do not validate data.

They only document expected types.


============================================================
3. TYPEDDICT PROBLEM
============================================================

Example:

    class User(TypedDict):

        name: str

        age: int

Data:

    user = {

        "name": "John",

        "age": "25"
    }

Problem:

    TypedDict describes structure.

    It does not validate data.


============================================================
4. SOLUTION - PYDANTIC
============================================================

Pydantic validates data automatically.

Example:

    from pydantic import BaseModel

    class User(BaseModel):

        name: str

        age: int


Create Object:

    user = User(

        name="John",

        age=25
    )

Data is validated.


============================================================
5. INTERVIEW DEFINITION
============================================================

Pydantic is a data validation and
data parsing library.

It uses Python Type Hints to:

    - Validate Data
    - Parse Data
    - Convert Data
    - Create Structured Models


============================================================
6. BASIC EXAMPLE
============================================================

    from pydantic import BaseModel

    class User(BaseModel):

        name: str

        age: int


    user = User(

        name="John",

        age=25
    )

Output:

    User(
        name='John',
        age=25
    )


============================================================
7. AUTOMATIC TYPE CONVERSION
============================================================

Input:

    user = User(

        name="John",

        age="25"
    )

Notice:

    age is string

Pydantic automatically converts:

    "25"

to

    25

Result:

    age => int

This is one reason why Pydantic is powerful.


============================================================
8. VALIDATION ERROR
============================================================

Example:

    user = User(

        name="John",

        age="ABC"
    )

Output:

    Validation Error

Reason:

    "ABC"

cannot be converted into integer.


============================================================
9. OPTIONAL FIELD
============================================================

    from typing import Optional

    from pydantic import BaseModel


    class User(BaseModel):

        name: str

        age: Optional[int] = None


Valid:

    User(name="John")

Valid:

    User(
        name="John",
        age=25
    )


============================================================
10. NESTED MODEL
============================================================

Example:

    class Address(BaseModel):

        city: str

        country: str


    class User(BaseModel):

        name: str

        address: Address


Data:

    user = User(

        name="John",

        address={
            "city": "Pune",
            "country": "India"
        }
    )


Pydantic validates entire object.
