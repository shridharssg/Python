1. Fibonacci Series Using Loop
---------------------------------------------------------

Question:

Print first N Fibonacci numbers.

Input:

n = 8

Output:

0 1 1 2 3 5 8 13

Code:

def fibonacci(n):

    a = 0
    b = 1

    for i in range(n):
        print(a, end=" ")
        a, b = b, a + b

2. Factorial Using Loop
---------------------------------------------------------

Question:

Find factorial of a number.

Input:

n = 5

Output:

120

Explanation:

5! = 5 × 4 × 3 × 2 × 1

Code:

def factorial(n):

    result = 1

    for i in range(1, n + 1):
        result *= i

    return result

3. Prime Number Check
---------------------------------------------------------

Question:

Check whether number is prime.

Input:

num = 13

Output:

True

Input:

num = 12

Output:

False

Code:

def is_prime(num):

    if num <= 1:
        return False

    for i in range(2, num):

        if num % i == 0:
            return False

    return True

4. Prime Numbers Between 1 To 100

1 to 100

Output:

2 3 5 7 11 13 17 19 ...
97

    prime = True

    for i in range(2, num):

            prime = False

9. Armstrong Number
---------------------------------------------------------

Question:

Check Armstrong Number.

Input:

153

Output:

True

Explanation:

1³ + 5³ + 3³ = 153

Code:

num = 153

temp = num

total = 0

while num > 0:

    digit = num % 10

    total += digit ** 3

    num //= 10

print(temp == total)

18. Flatten Nested List
---------------------------------------------------------

Input:

[1,[2,[3,4]],5]

Output:

[1,2,3,4,5]

Code:

def flatten(lst):

    result = []

    for item in lst:

        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)

    return result
