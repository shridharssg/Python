---------------------------------------------------------

19. Flatten Nested List
---------------------------------------------------------

Input:

[1,[2,[3,4]],5]

Output
:

[1,2,3,4,5]

---------------------------------------------------------

Solution:

def flatten(lst):
    result = []

    for item in lst:
        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)

    return result

data = [1,[2,[3,4]],5]

print(flatten(data))
