1. WHAT IS LIST COMPREHENSION?
------------------------------------------------------------

List Comprehension is a concise way to create lists in Python.
It combines looping, transformation, and filtering into a
single readable expression.

List Comprehension as Python's compact version of map(), 
filter(), and loops combined into a single line.

Traditional Way:

    numbers = [1, 2, 3, 4, 5]

    squares = []

    for n in numbers:
        squares.append(n * n)

    print(squares)

Output:

    [1, 4, 9, 16, 25]
	

List Comprehension:

    numbers = [1, 2, 3, 4, 5]

    squares = [n * n for n in numbers]

    print(squares)

Output:

    [1, 4, 9, 16, 25]


2. GENERAL SYNTAX
------------------------------------------------------------

    [new_value for item in iterable]

Example:

    numbers = [1, 2, 3]

    result = [x * 10 for x in numbers]

    print(result)

Output:

    [10, 20, 30]


3. NODE.JS EQUIVALENT
------------------------------------------------------------

JavaScript:

    const numbers = [1,2,3,4,5];

    const result = numbers.map(n => n * n);

    console.log(result);

Python:

    result = [n * n for n in numbers]


4. EXAMPLE - CONVERT STRINGS TO UPPERCASE
------------------------------------------------------------

Traditional:

    names = ["john", "sam", "mike"]

    result = []

    for name in names:
        result.append(name.upper())

List Comprehension:

    result = [name.upper() for name in names]

Output:

    ['JOHN', 'SAM', 'MIKE']




5. EXAMPLE - FILTER VALUES
------------------------------------------------------------

Traditional:

    numbers = [1,2,3,4,5,6,7,8]

    even_numbers = []

    for n in numbers:
        if n % 2 == 0:
            even_numbers.append(n)

List Comprehension:

    even_numbers = [n for n in numbers if n % 2 == 0]

Output:

    [2,4,6,8]


6. FILTER SYNTAX
------------------------------------------------------------

    [new_value for item in iterable if condition]

Example:

    numbers = [1,2,3,4,5]

    result = [x for x in numbers if x > 3]

Output:

    [4,5]


7. TRANSFORMATION + FILTER TOGETHER
------------------------------------------------------------

    numbers = [1,2,3,4,5,6]

    result = [n * n for n in numbers if n % 2 == 0]

Output:

    [4,16,36]



8. IF ELSE INSIDE LIST COMPREHENSION
------------------------------------------------------------

Syntax:

    [value_if_true if condition else value_if_false
     for item in iterable]

Example:

    numbers = [1,2,3,4,5]

    result = ["Even" if n % 2 == 0 else "Odd"
              for n in numbers]

Output:

    ['Odd', 'Even', 'Odd', 'Even', 'Odd']


9. REAL GENAI EXAMPLE #1
------------------------------------------------------------

    docs = [
        {"content": "AI"},
        {"content": "ML"},
        {"content": "LLM"}
    ]

Extract contents:

    contents = [doc["content"] for doc in docs]

Output:

    ['AI', 'ML', 'LLM']


10. REAL RAG EXAMPLE #2
------------------------------------------------------------

    retrieved_docs = [
        {"text": "Python"},
        {"text": "LangChain"},
        {"text": "Vector DB"}
    ]

    texts = [doc["text"] for doc in retrieved_docs]

Output:

    ['Python', 'LangChain', 'Vector DB']


11. REAL LANGCHAIN EXAMPLE
------------------------------------------------------------

    docs = retriever.invoke(query)

Each document contains:

    doc.page_content

Extract content:

    contents = [doc.page_content for doc in docs]

Equivalent:

    contents = []

    for doc in docs:
        contents.append(doc.page_content)


12. NESTED LIST COMPREHENSION
------------------------------------------------------------

    matrix = [
        [1,2],
        [3,4],
        [5,6]
    ]

Flatten:

    result = [item for row in matrix for item in row]

Output:

    [1,2,3,4,5,6]


13. COMMON INTERVIEW QUESTIONS
------------------------------------------------------------

Question 1:

Convert:

    [1,2,3,4,5]

To:

    [2,4,6,8,10]

Answer:

    result = [n * 2 for n in numbers]


Question 2:

Get only odd numbers.

Answer:

    result = [n for n in numbers if n % 2 != 0]


Question 3:

Convert all names to lowercase.

Answer:

    result = [name.lower() for name in names]


Question 4:

Extract all emails.

    users = [
        {"email": "a@gmail.com"},
        {"email": "b@gmail.com"}
    ]

Answer:

    emails = [user["email"] for user in users]


14. WHEN NOT TO USE LIST COMPREHENSION
------------------------------------------------------------

Avoid overly complex expressions:

    result = [
        process_user(user)
        for user in users
        if validate_user(user)
        and user["age"] > 18
        and user["country"] == "India"
        and user["active"]
    ]

Prefer readable code:

    result = []

    for user in users:
        if (
            validate_user(user)
            and user["age"] > 18
            and user["country"] == "India"
            and user["active"]
        ):
            result.append(process_user(user))


15. MUST-KNOW PATTERNS
------------------------------------------------------------

Mapping:

    [x * 2 for x in items]

Filtering:

    [x for x in items if condition]

Transform + Filter:

    [x.upper() for x in names if len(x) > 3]

Dictionary Extraction:

    [user["email"] for user in users]

Object Attribute Extraction:

    [doc.page_content for doc in docs]

Nested Loop:

    [item for row in matrix for item in row]
